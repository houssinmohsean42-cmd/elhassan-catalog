# كتالوج الجملة — elhassan home

كتالوج جملة تفاعلي للمعارض والتجار لمصنع **elhassan home – بيت الحسن للديكور المنزلي**.
موقع ثابت (HTML + CSS + JavaScript) بدون سيرفر، منشور على GitHub Pages.

## إزاي أحدّث الأسعار أو الأصناف؟

### الطريقة الأسهل: ملف `products.json`
1. افتح المستودع على GitHub واضغط على ملف `products.json` ثم زر التعديل (القلم).
2. كل صنف سطر بالشكل ده:

```json
{ "code": "DO01", "name": "طقم دوناتس سادة (متوفر 12 لون)", "pieces": null, "price": 110, "category": "أطقم دوناتس", "image": "images/DO01.jpg" }
```

- `code`: كود الصنف (حروف لاتينية وأرقام).
- `name`: اسم الطقم بالعربي.
- `pieces`: عدد القطع في الطقم.
- `price`: سعر الجملة بالجنيه.
- `category`: القسم (لازم يطابق أحد الأقسام الموجودة عشان الفلترة تظبط: أطقم دوناتس / أطقم ملكي ومفكر / فازات وتحف / مباخر وسكريات — أو أي قسم جديد وهيظهر زراره تلقائياً).
- `image`: صورة المنتج. حط اسم ملف الصورة جوه مجلد `images` (مثال: `"images/DO01.jpg"`) أو رابط صورة كامل. سيبه فاضي `""` وهتظهر صورة افتراضية أنيقة بالكود.
- `note` (اختياري): ملاحظة تظهر تحت السعر، مثل خيار سعر إضافي (مثال: `"إضافة الاسم: +15 ج"`).
3. اضغط Commit changes. التعديل يظهر على الموقع بعد دقيقة تقريباً.

### إزاي أضيف أو أغيّر صور المنتجات؟
1. من صفحة المستودع افتح مجلد `images` ثم Add file ← Upload files وارفع الصورة باسم كود الصنف (مثال: `DO01.jpg`). رفع صورة بنفس الاسم يستبدل القديمة.
2. الصور الحالية مأخوذة من كتالوج الجملة الأصلي (v8) ومربوطة بكل صنف في `products.json`.

### (اختياري) التحديث من Google Sheets بدل الملف
1. اعمل شيت بالأعمدة دي بالترتيب في أول صف: `code,name,pieces,price,category,image` (وعمود سابع اختياري `note` لملاحظة السعر)
2. من جوجل شيتس: ملف ← مشاركة ← نشر على الويب ← اختر CSV واضغط نشر وانسخ الرابط.
3. افتح ملف `config.js` في المستودع وحط الرابط بين علامتي التنصيص قدام `sheetsCsvUrl` ثم Commit.
4. الكتالوج هيقرأ من الشيت مباشرة (وأي تعديل في الشيت يظهر عند فتح الموقع). لو الرابط فاضي بيرجع يقرأ من `products.json`.

## ملاحظات
- كل الأصناف والأسعار والأقسام تتعدل من `products.json` أو الشيت بدون لمس باقي الملفات.
- زر الواتساب يجهّز رسالة الطلب للتاجر ويفتحها في واتساب على رقم المصنع — لا يُرسل أي شيء تلقائياً.
- السلة بتتحفظ على جهاز التاجر نفسه (localStorage) ومفيش أي بيانات بتتبعت لأي سيرفر.
